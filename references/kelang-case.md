# KelanG 网站：从迭代中提炼方法

这里记录设计决策的来由，帮助判断相似任务；不是要求其他人复制外观，也不包含原网站私有资料。

| 阶段 | 本案例遇到的问题 | 形成的方法 |
| --- | --- | --- |
| 内容起步 | 只有一个早期 AI 健身项目 | 清楚展示问卷、分析、画像和产品定义等实际工作，不伪造成熟产品 |
| 项目扩展 | 未来还会有多个项目 | 将项目列表与独立详情分离，预留复用的新增流程 |
| 首页收敛 | 内容过长，点击却只是往下滚 | 首页保留自我介绍和入口；按用户要求切到独立页面 |
| 风格寻找 | 通用模板感太强 | 用个人形象、黑白排版与克制的互动建立识别；黑白不是通用规则 |
| 转场迭代 | 加载动画、粗糙遮罩与突然进入 | 去除假加载，协调离开与进入节奏，保留阅读连续性 |
| 3D 形象 | 视频无法自由旋转，后续有真实 GLB | 区分参考图与几何素材，再按模型结构实现拖动、回正与表情 |
| 表情修正 | Wink 生硬、眼球外凸、耳部发白 | 结合眼睑形变、视线边界、材质和光照排查，不能靠堆动效修正造型 |
| 产品方向变化 | 从穿戴传感器转向视觉 AI 训练伙伴 | 更新内容和图像时服从最新定义；不要保留相互冲突的产品承诺 |
| 展示可信度 | 想要真实、有亲和力的产品图 | 概念渲染与实际产品分开标注，外观不要超出项目事实 |
| 双语与分享 | 希望英文默认、中文切换，手机也能看 | 翻译所有界面文本，验收窄屏与最终独立 HTML；模拟检查不等于真机 |
| 后续维护 | 希望发名称、图片和用途就能加项目 | 把输入、内容提炼、模板、路由和验证变成稳定流程 |
| 方法公开 | 希望别人也能复用 | 独立公开通用 Skill，不混入个人资产；核实发布后再写开源成果 |

可复用的是这些取舍，而不是某一张图、固定的动画秒数或特定工具组合。作品少也能建立可信网站，前提是把问题、个人贡献与当前阶段讲清楚。
