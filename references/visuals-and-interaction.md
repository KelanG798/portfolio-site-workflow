# 视觉、动态与 3D

## 先建立自己的视觉依据

从个人形象、项目特征、使用情境中找一个核心视觉线索。黑白可以克制，彩色也可以成熟；不要把单个案例的颜色推广给所有人。用字体层次、留白、图像质量和稳定对齐建立品质，再考虑装饰。

参考站点是研究材料：描述学到的节奏、构图与互动，而不是只说“高级”。只声称看过实际读取过的页面。AI 生成产品图需标注为概念，并保留实际产品资料与渲染图的区别。

## 页面转场

定义离开、切换、进入三个状态。淡出/轻移完成后再更换内容，下一页从轻微偏移逐渐进入，避免旧页结束后新页突然弹出。时长是可调整的起点，不是固定标准；初版可从离开约 180–280ms、进入约 350–550ms 观察阅读感受。

连续点击时取消旧任务或复用当前状态，避免动画排队。恢复浏览器返回、焦点和可见状态；转场层不能永久挡住页面。用户关闭加载动画后，不要换名称重新加一个。

为 `prefers-reduced-motion: reduce` 提供立即切换或极轻渐变。不能只靠动效表达导航已发生。

## 轻量空间感

图片卡片轻微跟随鼠标倾斜，可先限制在约 3–6 度。指针离开恢复，触屏与减少动态时保持静态。不要把正文、按钮一起大幅旋转，也不要让视觉效果影响点击区域。

## 可动头像与模型

先检查素材：GLB/glTF 是否包含网格、纹理、骨骼、表情形变或动画。视频/三视图只能提供外观线索，不能直接获得完整可转动的几何。缺表情结构时，说明是否需要绑定、重建或简化方案；不承诺只改 CSS 就能修好模型。

- 拖动与回正：记录正面姿态；松手后插值或用阻尼弹簧回正；新拖动中止回弹；处理 pointercancel，避免卡住。手机保留纵向阅读能力。
- 视线跟随：限制小幅范围，平滑延迟，不要求眼睛时刻精确盯着指针。眼球保持在眼眶内，转动优先于平移。
- 微笑与 Wink：优先使用已有形变/骨骼；眼睑闭合而非把整个眼球放大挤压。Wink 可配轻微嘴角和头部变化，避免机械地夹眼。多次点击时状态有序，结束恢复自然表情。
- 材质与配件：检查耳朵和面部颜色、粗糙度及光照差异；耳机位置要从正面、侧面验证入耳关系。材质白斑不一定是贴图颜色，也可能是高光或法线问题。
- 性能与降级：限制像素比例/渲染负担；不可见时暂停；销毁监听和渲染资源；模型失败时显示静态图，不阻挡文字。处理导出文件过大的传输成本。

Blender、Three.js、model-viewer 等是实现选项，是否使用取决于素材和环境，不是全部必装。

## 图片与辅助交互

大图必须有清晰关闭按钮，支持 Escape 和背景关闭，并在关闭后恢复原按钮焦点。进入弹层时避免底层误触。链接、切换按钮和关闭按钮应能用键盘访问；不要把必要内容只藏在 hover 状态中。
